Log Analyzer - Project Documentation
=======================================

Overview
--------
Log Analyzer is a set of small Python command-line utilities for log analysis, system checks, CPU monitoring, and ONNX inference experiments.

Project Files
-------------
- log_parser.py: scans .log files for ERROR and WARNING lines and writes a summary report.
- system_check.py: runs basic environment and host checks.
- hw_monitor.py: generates synthetic CPU load, samples utilization, and saves a plot.
- inference_agent.py: runs MobileNetV2 ONNX inference on available execution providers.
- test_parser.py: unit tests for log parsing.
- test_system_check.py: unit tests for command helper behavior.
- logs/: sample log files used by the parser.
- mobilenetv2.onnx: ONNX model used by inference_agent.py.

Requirements
------------
- Python 3.8 or newer
- pytest
- psutil
- matplotlib
- numpy
- onnxruntime

Install dependencies:

python3 -m pip install pytest psutil matplotlib numpy onnxruntime

If GPU inference is required, install an ONNX Runtime build that matches the target platform, such as onnxruntime-gpu for CUDA systems.

Log Analyzer
------------
File: log_parser.py

What it does:
- Accepts a directory path with --dir.
- Finds files ending in .log.
- Extracts lines containing uppercase ERROR and WARNING.
- Writes a structured report to report.txt.

Run:
python3 log_parser.py --dir logs

Output:
- report.txt in the project root
- A section for each log file
- Error and warning counts for each file

System Checker
--------------
File: system_check.py

What it does:
- Checks Python version with python3 --version
- Checks disk space with df -h /
- Checks disk usage threshold with df / and fails above 90%
- Checks memory usage using psutil when available, otherwise free
- Prints OS information with uname -a
- Prints Git version with git --version

Behavior:
- Each check returns pass/fail.
- The program prints a summary and exits with status code 1 if any check fails.

Run:
python3 system_check.py

Hardware Monitor
----------------
File: hw_monitor.py

What it does:
- Detects CPU model with lscpu
- Detects GPU information with lspci
- Reports that no NPU is detected on this hardware
- Starts a synthetic CPU workload across all cores
- Samples CPU utilization with psutil
- Prints average, peak, and minimum CPU usage
- Saves a plot to utilization.png

Run:
python3 hw_monitor.py --duration 10

Output:
- utilization.png
- Console summary of sampled CPU usage

Inference Agent
---------------
File: inference_agent.py

What it does:
- Loads mobilenetv2.onnx
- Runs inference on CPU, GPU, NPU, or all selected devices
- Uses onnxruntime execution providers when available
- Monitors utilization and saves a plot

Device options:
- cpu
- gpu
- npu
- all

Run:
python3 inference_agent.py --device all --duration 10

Options:
- --device: device selection, default cpu
- --duration: runtime in seconds, default 10
- --model: path to the ONNX model, default mobilenetv2.onnx

If the model file is missing, download it with wget or curl from the ONNX model repository.

Testing
-------
Run all tests with:
pytest -q

Current test coverage:
- log parsing behavior
- log file filtering
- run_command() handling for a nonexistent command
- basic system check helper behavior

Generated Files
--------------
The following files are generated by running the scripts:
- report.txt
- utilization.png
- inference_utilization.png

Notes
-----
- The scripts rely on external system commands such as lscpu, lspci, df, free, uname, and git.
- GPU and NPU support depends on hardware and the installed ONNX Runtime build.
